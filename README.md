# termen-app.github.io

The public site of **Termen**, an iPhone app that shows your Mac's cmux terminal.

GitHub Pages serves this repository at <https://termen-app.github.io/>.

## Pages

| Page | URL | File |
|---|---|---|
| Home | <https://termen-app.github.io/> | `index.html` |
| Privacy Policy | <https://termen-app.github.io/privacy/> | `privacy/index.html` |

The Privacy row in the app (Settings › About › Privacy) opens the privacy policy. App Store
Connect uses the same URL. Do not move or rename `privacy/index.html`: an app that is already
installed keeps the old URL.

## Change the privacy policy

The policy has two copies:

1. `PRIVACY.md` in the Termen source repository.
2. `privacy/index.html` in this repository.

Change both, and change the date at the top and at the bottom of the page. GitHub Pages
publishes a push to `main` in about a minute.

## Contact
